# 最小二乘法拟合直线 —— 原理与实现途径

> 本文档拆解《水下机器人设计》期末报告中巡检技术路线所采用的**最小二乘法拟合直线**方案，
> 并给出在 `P1 巡线/line_detector.py` 中的自实现途径（替代 `cv2.fitLine`）。

---

## 一、报告中的技术路线回顾

报告巡线模块的核心选择是**最小二乘法拟合直线**，而非主流的霍夫直线检测。理由如下：

| 对比维度 | 霍夫直线检测 | 最小二乘法拟合 |
|---------|------------|--------------|
| 抗噪声性能 | 易受杂乱线条、噪声干扰 | 对离散噪声点有天然平滑作用 |
| 转弯过渡 | 线段断裂处易跳变 | 连续过渡，拟合结果平滑 |
| 算力占用 | 较低（参数空间投票） | 中等（矩阵运算） |
| 适用场景 | 清晰、孤立的直线段 | 带噪声、可能弯曲的连续轨迹 |

在本项目中，识别目标（海洋生物卡片）内含有大量杂乱线条，霍夫变换会产生大量误检直线，
导致机器人控制卡顿、振荡甚至偏离线路。最小二乘拟合将所有属于引导线的像素点作为整体，
拟合出一条最优直线，在转弯处也能连续过渡，有利于控制稳定。

**完整流水线：**
```
原始帧 → 预处理 → HSV颜色分割(inRange) → 形态学处理 → 轮廓提取
       → 取最大轮廓 → 图像矩算重心(offset) → 最小二乘拟合直线(angle)
```

## 二、最小二乘法的数学原理

### 2.1 普通最小二乘（OLS, Ordinary Least Squares）

给定 $n$ 个数据点 $(x_i, y_i)$，假设拟合直线为 $y = kx + b$。
最小二乘的目标是**最小化残差平方和**：

$$
S(k, b) = \sum_{i=1}^{n} (y_i - kx_i - b)^2
$$

对 $k$ 和 $b$ 分别求偏导并令其为零，得到**正规方程组**：

$$
\begin{cases}
\frac{\partial S}{\partial k} = -2\sum x_i(y_i - kx_i - b) = 0 \\[4pt]
\frac{\partial S}{\partial b} = -2\sum (y_i - kx_i - b) = 0
\end{cases}
$$

解得：

$$
k = \frac{n\sum x_i y_i - \sum x_i \sum y_i}{n\sum x_i^2 - (\sum x_i)^2}, \qquad
b = \frac{\sum y_i - k\sum x_i}{n}
$$

**局限性：** OLS 只最小化 $y$ 方向的残差（假设 $x$ 无误差）。当直线接近垂直时，
斜率 $k \to \infty$，数值不稳定。巡线场景中引导线通常接近垂直（沿画面 $y$ 轴方向），
直接用 $y = kx + b$ 拟合会出现数值问题。

### 2.2 总体最小二乘（TLS, Total Least Squares）—— 本项目采用

TLS 同时考虑 $x$ 和 $y$ 方向的误差，最小化**点到直线的正交距离平方和**：

$$
S = \sum_{i=1}^{n} d_i^2, \qquad d_i = \frac{|ax_i + by_i + c|}{\sqrt{a^2 + b^2}}
$$

其中直线一般式为 $ax + by + c = 0$。

#### 基于 PCA 的等价求解

TLS 可以通过**主成分分析（PCA）**高效求解，步骤如下：

**Step 1：计算质心**

$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i, \qquad
\bar{y} = \frac{1}{n}\sum_{i=1}^{n} y_i
$$

**Step 2：中心化数据**

$$
\tilde{x}_i = x_i - \bar{x}, \qquad \tilde{y}_i = y_i - \bar{y}
$$

**Step 3：构建协方差矩阵**

$$
C = \begin{bmatrix}
\sum \tilde{x}_i^2 & \sum \tilde{x}_i \tilde{y}_i \\
\sum \tilde{x}_i \tilde{y}_i & \sum \tilde{y}_i^2
\end{bmatrix}
$$

**Step 4：特征值分解**

$$
C \mathbf{v} = \lambda \mathbf{v}
$$

得到两个特征值 $\lambda_1 \geq \lambda_2$ 及对应的特征向量 $\mathbf{v}_1, \mathbf{v}_2$。

- **最大特征值 $\lambda_1$ 对应的特征向量 $\mathbf{v}_1 = (v_x, v_y)$**：
  数据方差最大的方向，即**拟合直线的方向向量**。
- **最小特征值 $\lambda_2$ 对应的特征向量**：数据方差最小的方向，即直线的法向量。
- 直线必经过质心 $(\bar{x}, \bar{y})$。

**为什么等价于 TLS？** 点到直线的正交距离平方和，等于数据在直线法向量方向上的方差。
最小化距离平方和 = 寻找方差最小的方向 = 协方差矩阵最小特征值对应的特征向量方向。
其正交方向（最大特征值方向）就是直线方向。

### 2.3 角度计算

拟合直线方向向量为 $(v_x, v_y)$，垂直方向（机器人前进方向，画面 $y$ 轴正方向）为 $(0, 1)$。
直线与垂直方向的夹角：

$$
\theta = \arctan2(v_x, v_y)
$$

- $\theta > 0$：直线向右偏，机器人需右转对齐
- $\theta < 0$：直线向左偏，机器人需左转对齐

为避免方向向量反转导致角度符号跳变，统一约束 $v_y > 0$（若 $v_y < 0$ 则取反）。

## 三、在巡线代码中的实现途径

### 3.1 数据来源

从 `cv2.findContours` 得到的最大轮廓 `largest` 中提取所有像素点坐标：

```python
# largest 形状为 (N, 1, 2)，reshape 为 (N, 2)
points = largest.reshape(-1, 2).astype(np.float64)
x = points[:, 0]
y = points[:, 1]
```

### 3.2 自实现最小二乘拟合（PCA 方法）

```python
def _least_squares_fit_line(points):
    """
    基于 PCA 的总体最小二乘直线拟合

    Args:
        points: (N, 2) 数组，每行一个点 (x, y)

    Returns:
        (vx, vy, x0, y0): 方向向量 + 直线上一点（质心）
    """
    n = points.shape[0]
    if n < 2:
        return 0.0, 1.0, 0.0, 0.0

    # Step 1: 质心
    x_mean = np.mean(points[:, 0])
    y_mean = np.mean(points[:, 1])

    # Step 2: 中心化
    x_centered = points[:, 0] - x_mean
    y_centered = points[:, 1] - y_mean

    # Step 3: 协方差矩阵 (2x2)
    sxx = np.sum(x_centered ** 2)
    syy = np.sum(y_centered ** 2)
    sxy = np.sum(x_centered * y_centered)
    cov = np.array([[sxx, sxy],
                    [sxy, syy]])

    # Step 4: 特征值分解
    # eigvals 升序排列，eigvecs 列向量为对应特征向量
    eigvals, eigvecs = np.linalg.eigh(cov)

    # 最大特征值对应的特征向量 = 直线方向向量（最后一列）
    vx = eigvecs[0, 1]
    vy = eigvecs[1, 1]

    # 统一方向：vy > 0
    if vy < 0:
        vx, vy = -vx, -vy

    return float(vx), float(vy), float(x_mean), float(y_mean)
```

### 3.3 与 `cv2.fitLine` 的对应关系

| 项目 | `cv2.fitLine(contour, DIST_L2, 0, 0.01, 0.01)` | 自实现 PCA-TLS |
|------|----------------------------------------------|---------------|
| 原理 | M-估计器，`DIST_L2` 退化为最小二乘 | 协方差矩阵特征分解 |
| 输出 | `[vx, vy, x0, y0]` 方向向量+线上点 | `[vx, vy, x0, y0]` 方向向量+质心 |
| 数值稳定性 | 高（OpenCV 内部优化） | 高（eigh 针对对称矩阵） |
| 依赖 | 需 OpenCV | 仅需 NumPy |
| 垂直直线 | 稳定 | 稳定（正交距离，无斜率发散） |

> `cv2.fitLine` 的 `DIST_L2` 模式本质上也是最小二乘，但它是 OpenCV 黑盒实现。
> 自实现版本使用 NumPy 的 `eigh`（针对实对称矩阵优化），数学上等价且透明可控。

### 3.4 角度计算封装

```python
def _calc_vertical_angle(self, contour):
    """计算轮廓拟合直线与垂直方向的夹角（自实现最小二乘）"""
    points = contour.reshape(-1, 2).astype(np.float64)
    vx, vy, _, _ = self._least_squares_fit_line(points)

    # atan2(vx, vy) = 偏离垂直方向的角度
    angle_rad = np.arctan2(vx, vy)
    return float(np.degrees(angle_rad))
```

## 四、为什么不用简单的 $y = kx + b$ 回归

| 问题 | 说明 |
|------|------|
| 垂直直线斜率发散 | 引导线接近垂直时 $k \to \infty$，浮点溢出 |
| 仅考虑 y 方向误差 | 图像中 x、y 坐标均有量化误差，OLS 假设 x 精确不成立 |
| 轮廓点分布不均 | 轮廓提取的点沿边界分布，不是均匀采样，y 回归会被端点主导 |

PCA-TLS 方法通过正交距离最小化，完美规避了上述问题，是图像直线拟合的标准做法。
